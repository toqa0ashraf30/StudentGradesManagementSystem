# 🎓 نظام إدارة درجات الطلاب (Student Grade Management System)

تطبيق مكتب بسيط ومباشر لإدارة درجات الطلاب وحساب الإحصائيات الأكاديمية.

## 📌 وصف موجز للمشروع

برنامج مخصص لمساعدة المحاضرين على إدخال درجات الطلاب، تعديلها، حذفها، وعرض إحصائيات سريعة (مثل الأعلى، الأقل، والمعدل) بالإضافة لرسومات بيانية تفاعلية لتمثيل توزيع العلامات.

## 🛠️ التقنيات والبيئة المستخدمة

* **لغة البرمجة:** Java (نسخة JDK 17 أو أعلى)
* **واجهة المستخدم:** JavaFX
* **تصميم الواجهات:** Scene Builder (ملفات FXML)
* **بيئة التطوير (IDE):** NetBeans IDE

## 📁 هيكلية مجلدات المشروع (Project Structure)

```text
StudentGradeManagementSystem/
├── src/
│   └── studentmanagement/
│       ├── MainApp.java           # الكلاس الرئيسي لتشغيل التطبيق
│       ├── sController.java       # كلاس التحكم بالواجهة والأحداث
│       ├── studentBag.java        # كلاس الحقيبة البرمجية والمصفوفات
│       ├── StudentModel.java      # كلاس موديل بيانات الطالب
│       ├── s.fxml                 # ملف تصميم الواجهة من Scene Builder
│       └── style.css              # ملف تنسيقات الـ CSS للواجهة
├── nbproject/                     # إعدادات مشروع NetBeans
├── build.xml                      # ملف بناء المشروع (Ant Build)
└── README.md                      # توثيق المشروع
```

## 🏗️ الكلاسات الأساسية (Project Classes)

1. **`MainApp.java`**: الكلاس الرئيسي لتشغيل البرنامج وتحميل واجهة الـ FXML.
2. **`sController.java`**: كلاس التحكم بالواجهة ومعالجة ضغطات الأزرار والإدخالات.
3. **`studentBag.java`**: كلاس هيكل البيانات المخصص الذي يحتوي على المصفوفات المتوازية لدعم عمليات الإضافة، الحذف، التعديل، والحسابات.
4. **`StudentModel.java`**: كلاس لتمثيل بيانات الطالب (الرقم الجامعي، الاسم، والدرجة).

## 🚀 كيفية التشغيل

1. افتحي المشروع باستخدام برنامج **NetBeans IDE**.
2. تأكدي من ربط مكتبة **JavaFX** بالـ Build Path.
3. شغّلي الملف الرئيسي `MainApp.java`.
